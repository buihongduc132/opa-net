## Fix 1 (v1): Drop spoofable OPA_GATE_INTERNAL guard (Critical)

- **Issue**: Inheritable `OPA_GATE_INTERNAL=1` allowed callers to bypass shim interception and policy evaluation completely (`OPA_GATE_INTERNAL=1 /opt/opa-gate/bin/git checkout feature-evil` passed through directly to real git).
- **Changes**:
  - Removed recursion guard check, `export OPA_GATE_INTERNAL=1`, and `unset OPA_GATE_INTERNAL` from `scripts/.opa-gate-shim`.
  - Removed `export OPA_GATE_INTERNAL=1` from `scripts/opa-gate-audit-append`.
  - Deployed updated shim and audit-append to `/opt/opa-gate/scripts/` and `/opt/opa-gate/bin/.opa-gate-shim`.
  - Added unit tests in `tests/unit/shim/opaGateShim.test.ts`.
- **Evidence**:
  - RED before: `OPA_GATE_INTERNAL=1 /opt/opa-gate/bin/git checkout feature-evil` returned exit 1 (`error: pathspec 'feature-evil' did not match any file(s) known to git`), bypassing opa-gate without audit entry.
  - GREEN after: `OPA_GATE_INTERNAL=1 /opt/opa-gate/bin/git checkout feature-evil` returns exit 2 (`BLOCKED: git checkout feature-evil (rule: custom:761ff53e)`), with `audit.jsonl` entry source `opa`.

## Fix OT-2 / V7a: Retire/repoint legacy ~/.local/bin/git wrapper (In-scope)

- **Issue**: `~/.local/bin/git` (legacy August wrapper) was earlier on PATH than `/opt/opa-gate/bin`, shadowing the universal shell gate and allowing commands to bypass opa-gate in shells with `~/.local/bin` first.
- **Changes**:
  - Repointed `/home/bhd/.local/bin/git` to `/opt/opa-gate/bin/git` symlink.
  - Preserved `/home/bhd/.local/bin/git.legacy-wrapper.bak`.
- **Evidence**:
  - RED before: `which git` -> `/home/bhd/.local/bin/git` (legacy script), `git checkout feature-evil` bypassed opa-gate (exit 1 from git).
  - GREEN after: `which git` -> `/home/bhd/.local/bin/git` -> `/opt/opa-gate/bin/git`, `git checkout feature-evil` denied with exit 2 (`BLOCKED: git checkout feature-evil (rule: custom:761ff53e)`).
