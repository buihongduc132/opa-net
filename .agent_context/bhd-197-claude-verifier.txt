### 1. CRITICAL — `&&`, `||`, `|`, newline compound bypass. Verbatim deny-class command is ALLOWED.
Requirement: *"Compound bash -c must classify the INNER find/grep, not only bash."* `src/cli/run.ts:139-152` splits on `;` **only**.

```
$ bun bin/pi-opa-net.js eval 'true && find /home/bhd -name goal.json -mmin -15' --json
{"decision":"allow","action":"allow","source":"opa","reasons":[],
 "input":{"raw":"true && find /home/bhd -name goal.json -mmin -15","program":"true",
 "args":["find","/home/bhd","-name","goal.json","-mmin","-15"],"parse_confidence":"partial"},...}
EXIT=0
```
`source:"opa"` — a genuine policy allow, not the fail-open race. Full matrix (each retried past fail-open):

| command | decision |
|---|---|
| `echo hi; find /home/bhd` | deny ✓ |
| `true && find /home/bhd -name goal.json -mmin -15` | **allow** |
| `cd /tmp \|\| find /home/bhd` | **allow** |
| `echo hi \| find /home/bhd` | **allow** |
| `find /home/bhd` (newline-separated) | **allow** |
| `cd /tmp && find /home/bhd` | **allow** |
| `bash -c 'cd /home/bhd && find .'` | **allow** |
| `sh -c 'true && find /home/bhd'` | **allow** |
| `true && grep -rl BHD-156 ~/.hermes` | **allow** |

`bash -c 'cd /home/bhd && find .'` is the natural agent idiom and defeats the gate entirely. No test covers any non-`;` separator.

### 4. HIGH — `block-home-wide-grep` does not block home-wide grep.
Rule ID and parent requirement ("Gate home-wide find / **recursive grep**") vs. implementation (`policy/safety.rego`, hermes-only predicates):
```
grep -rl BHD-156 ~/.hermes --include=*.db  => deny   block-home-wide-grep
```

The catalog message is honest ("Recursive grep of `~/.hermes`"), so parity passes — but the rule *name* and the ticket promise home-wide coverage that does not exist. Silent scope drop.

### 6. MEDIUM — command-prefix evasions (same `find` program, undetected).
